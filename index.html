▶ Spotify Cue Board

Tap a song to start at its saved cue point
Choose a size that fits your iPad screen. Changes save automatically.

1. Connect your Spotify Premium account

Create a personal app at Spotify Developer Dashboard, then paste the Client ID here. In the Spotify app settings, add the exact Redirect URI displayed below. Host this file on HTTPS (such as GitHub Pages); it won't authenticate reliably when opened as a local file.

Your client ID and cue buttons are stored in this browser. This app uses Spotify's PKCE login; no client secret is needed.

2. Choose where Spotify plays

Open Spotify and start playing something briefly to make your iPad or another Spotify Connect device available. Select it above. A button sends a Spotify playback request; timing is network-dependent.

3. Your cue buttons

To rearrange: hold the ↕ Move handle and drag a song to a new position. Or tap ◀ / ▶. The order saves automatically.

Add a song button

In Spotify, tap Share → Copy Link, then paste it here. Cue points are saved on this device. Example: 1:15 starts 75 seconds into the track.

Important limitations

This is a personal-use prototype. It does not bypass Spotify Premium, download songs, or provide sample-accurate instant audio. Spotify may reject playback controls on some devices, and mobile browser playback can require an additional user gesture. Spotify API quotas and platform policies apply. Do not rely on it for a live show until tested with your specific iPad and output device.
