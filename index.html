1. Connect your Spotify Premium account

Create a personal app at Spotify Developer Dashboard, then paste the Client ID here. In the Spotify app settings, add the exact Redirect URI displayed below. Host this file on HTTPS (such as GitHub Pages); it won't authenticate reliably when opened as a local file.

Your client ID and cue buttons are stored in this browser. This app uses Spotify's PKCE login; no client secret is needed.

2. Choose where Spotify plays

Select a playback device to check whether fading is supported.

Open Spotify and start playing something briefly to make your iPad or another Spotify Connect device available. Select it above. A button sends a Spotify playback request; timing is network-dependent.

Add a song button

In Spotify, tap Share → Copy Link, then paste it here. Tap Fade on a playing song to lower its volume and pause at the end. A green Played check appears when the playback request succeeds; Reset Played clears them all. Optionally enter an automatic fade start time (e.g. 2:30 means at 2:30 into that song). Fade timing depends on Spotify and the selected device. Cue points are saved on this device. Example: 1:15 starts 75 seconds into the track.

Important limitations

This is a personal-use prototype. Spotify device support varies: some devices cannot fade remotely and will pause instead. It does not bypass Spotify Premium, download songs, or provide sample-accurate instant audio. Fade out uses stepped Spotify Connect volume changes, not a locally rendered audio fade. It may be uneven or unavailable on some devices. If volume changes fail, the app still attempts to pause the song. Automatic fade timing requires this page to remain open and active; background iPad tabs can delay it. Spotify may reject playback controls on some devices, and mobile browser playback can require an additional user gesture. Spotify API quotas and platform policies apply. Do not rely on it for a live show until tested with your specific iPad and output device.
