1. Connect your Spotify Premium account

Create a personal app at Spotify Developer Dashboard, then paste the Client ID here. In the Spotify app settings, add the exact Redirect URI displayed below. Host this file on HTTPS (such as GitHub Pages); it won't authenticate reliably when opened as a local file.

Your client ID and cue buttons are stored in this browser. This app uses Spotify's PKCE login; no client secret is needed.

Open Spotify

Select your player above, or tap Find Player to refresh the list. If none appears, open Spotify, start a track, return here, and tap Find Player again. If Spotify recognises a current player but doesn't list it, choose the active player option in the selector. Spotify may not expose every iPad device to the Web API.

To rearrange: touch and hold ↕ Move, then drag over the button you want to swap positions with. Or tap ◀ / ▶. The order saves automatically.

Add a song button

In Spotify, tap Share → Copy Link, then paste it here. Tap Fade on a playing song to lower its volume and pause at the end. A red Played check appears when the playback request succeeds; Reset Played clears them all. Optionally enter an automatic fade start time (e.g. 2:30 means at 2:30 into that song). Fade timing depends on Spotify and the selected device. Cue points are saved on this device. Example: 1:15 starts 75 seconds into the track.

Important limitations

This is a personal-use prototype. Spotify device support varies: some devices cannot fade remotely and will pause instead. It does not bypass Spotify Premium, download songs, or provide sample-accurate instant audio. Fade out uses stepped Spotify Connect volume changes, not a locally rendered audio fade. It may be uneven or unavailable on some devices. If volume changes fail, the app still attempts to pause the song. Automatic fade timing requires this page to remain open and active; background iPad tabs can delay it. Spotify may reject playback controls on some devices. iPad volume cannot be controlled directly by browser JavaScript; if Spotify reports supports_volume=false, Fade uses Pause instead. Playback device IDs can expire and must be refreshed. Spotify API quotas and platform policies apply. Do not rely on it for a live show until tested with your specific iPad and output device.
